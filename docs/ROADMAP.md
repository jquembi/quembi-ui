# Roadmap de produto

## Entregue no starter

- [x] Estrutura npm workspaces React + Vue + website
- [x] Identidade visual e website responsivo
- [x] Catálogo com pesquisa, filtros, preview e exemplos de uso
- [x] Oito componentes Free React e oito equivalentes Vue
- [x] Quatro demonstrações visuais conceptuais Premium
- [x] Modelo de licenças documentado e contacto opcional por e-mail
- [x] Pipeline CI, documentação e configuração de deploy estático

## Prioridade 1 — robustez do produto

- [ ] Testes unitários com Vitest + Testing Library / Vue Test Utils
- [ ] Testes de UI, snapshots e regressão visual
- [ ] Accessibility audit WCAG 2.2 AA; gestão completa do foco nos diálogos
- [ ] Showcase Vue real num microfrontend isolado ou sandbox
- [ ] Internacionalização pt-AO, pt-PT, en; ajustes de escrita
- [ ] Tokens de design, temas claro/escuro nos componentes e gerador de temas

## Prioridade 2 — distribuição

- [ ] Build npm correcto, exports em dist, tipos gerados e versionamento
- [ ] Publicação de pacotes Free e comando CLI opcional de cópia
- [ ] Documentação detalhada das APIs e playground de propriedades
- [ ] Testes de integração em projectos React, Vue, Next.js e Nuxt
- [ ] Pesquisa avançada, URLs por componente, SEO e metadados dedicados

## Prioridade 3 — Premium e comércio

- [ ] Desenvolver de facto os layouts Premium apresentados nas demos
- [ ] Definir contratos, preços, condições fiscais e atendimento comercial
- [ ] Repositório Premium privado e pipeline de builds privados
- [ ] Backend para conta, pedidos, pagamento e emissão/revogação de licenças
- [ ] Webhooks com assinatura verificada e downloads autenticados
- [ ] Área de cliente, histórico, actualizações e suporte

Não tratar funcionalidades por implementar como disponíveis nos materiais de marketing.
