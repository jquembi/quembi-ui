# Contribuir para Quembi UI

Contribuições a componentes **Free** são bem-vindas. Antes de abrir um PR:

1. Cria uma branch específica e limita as alterações ao âmbito proposto.
2. Mantém equivalência visual e semântica React/Vue sempre que acrescentares um componente.
3. Evita dependências desnecessárias; componentes devem ter estados, foco e rótulos acessíveis.
4. Actualiza o catálogo, exemplos e documentação quando mudares API, variantes ou comportamento.
5. Executa `npm run verify` e `npm run check`; acrescenta testes quando o projecto os disponibilizar.
6. Nunca comites segredos, dados pessoais reais ou fonte Premium no repositório público.

O mantenedor pode solicitar revisões de acessibilidade, documentação e compatibilidade antes de aceitar alterações. Política de suporte e código de conduta ainda precisam ser definidos pelo proprietário.
